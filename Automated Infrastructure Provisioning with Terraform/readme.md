# 🚀 Automated Infrastructure Provisioning with Terraform

## 📌 Project Overview
This project demonstrates how to use **Terraform** to automate the provisioning of AWS infrastructure. It focuses on Infrastructure as Code (IaC) principles to deploy a consistent, repeatable, and scalable cloud environment.

The infrastructure includes a custom **VPC**, **public subnet**, **internet gateway**, **security group**, and an **EC2 instance** created automatically using Terraform.

---

## 🛠️ Tools & Technologies
- **Terraform**
- **AWS (EC2, VPC, Subnet, Security Groups)**
- **Ubuntu Linux**
- **Git & GitHub**
